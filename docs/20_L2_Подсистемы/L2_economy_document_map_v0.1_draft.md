## 1) Что из текущего черновика уже покрывает уровни

### L1 (верхнеуровневые принципы)
Из исходного черновика можно сразу вынести:
- философию закрытой экономики;
- принцип «ценность не создаётся из воздуха»;
- границы монетизации (покупка/выкуп персонажей);
- системные антиинфляционные механики (старение, смерть, утраты, амортизация);
- принцип бесшовного масштабирования управления от 1 персонажа к сообществу.

### L2 (подсистемы)
Черновик уже содержит материал минимум для 6 подсистем:
1. Контур денег и ликвидности фонда.
2. Жизненный цикл персонажа (старение, износ, смерть).
3. Производственный контур (труд → ресурсы → износ).
4. Демография (размножение, энтропия поколений).
5. Рынки взаимодействия игроков (вторичный рынок, аренда).
6. Социально-управленческий контур (благополучие, трудовой рынок, агрегация показателей).

### L3 (операции)
Из текста можно выделить набор операционных сценариев:
- покупка персонажа у системы;
- выкуп персонажа системой;
- вторичная продажа персонажа (атомарная сделка);
- заключение/исполнение/завершение аренды;
- расчёт старения за тик;
- расчёт производительности и износа по рабочему времени;
- обработка кризисного поведения наёмных работников;
- обновление благополучия поселения;
- агрегирование показателей для группы/области видимости.

### L4 (исполнительные спецификации)
На основании черновика можно сделать две ветки:
- UX-спеки: интерфейс рынков, контракты аренды, панели состояния, шестиугольный индикатор, progressive revelation;
- Code-спеки: формулы, входные параметры, события, ограничения инвариантов, API/таблицы состояния.

## 4) Преобразование открытых вопросов в документы

Открытые вопросы из черновика лучше сразу оформить в отдельный backlog:

- `docs/90_Глоссарий_и_реестры/open_questions_economy.md`

Рекомендуемые поля записи:
- ID вопроса;
- формулировка гипотезы;
- какие параметры неизвестны;
- какие симуляции/тесты нужны;
- критерий принятия решения;
- дедлайн и ответственный.

## 5) Приоритетность работ

1. Сначала закрепить L1-принципы (иначе L2 будет противоречивым).
2. Затем L2 по деньгам, износу и труду (это ядро баланса).
3. Затем L3 по рыночным операциям и симуляции тиков.
4. В конце L4 (UX и код) после фиксации инвариантов.

## Критерии готовности
- Есть согласованный перечень стартовых документов L1–L4.
- Для каждого документа понятна цель и область ответственности.
- Определён порядок выпуска черновиков.
