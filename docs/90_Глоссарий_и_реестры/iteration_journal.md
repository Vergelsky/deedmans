# Журнал итераций

Единый реестр итераций документации, чтобы история изменений не расползалась по отдельным L1/L2-файлам.

## Правило ведения
- Для **каждой итерации** переносить одну строку из локального `Iteration Log` в таблицу ниже.
- Запись добавляется сразу после завершения итерации (в том же коммите/PR, где внесены изменения в документы).

## Реестр

| Iteration ID | Дата | Фокус | L1 changed | L2 changed | Статус | Open questions | Ссылки на коммит/PR |
|---|---|---|---|---|---|---|---|
| _TBD_ | _YYYY-MM-DD_ | _Краткое описание фокуса итерации_ | _Да/Нет + файл(ы)_ | _Да/Нет + файл(ы)_ | _draft/review/approved_ | _Открытые вопросы или `—`_ | _hash коммита / URL PR_ |
