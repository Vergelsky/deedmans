## Содержание уровня
- Invariant A: запрещена передача персонажа без синхронной оплаты в OP-ECON-0002.
- Invariant B: любой тик старения уменьшает остаточный жизненный ресурс неотрицательно.
- Invariant C: безрисковый цикл buy/sell не должен давать гарантированный плюс в ожидании.
- Event contract: `trade_settled`, `rent_started`, `wear_tick_applied`, `wellbeing_updated`.
